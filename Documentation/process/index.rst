====================
Contributing to EOLA
====================

These pages describe how a change reaches EOLA: which branch it targets and
what a commit and a pull request carry. A suspected vulnerability follows
its own path, set out in :doc:`security-bugs`.

* :doc:`contributing` -- commit format, sign-off, and what a pull request
  carries.
* :doc:`branching` -- ``eola-next``, ``main`` and release tags.
* :doc:`patch-checks` -- the checks a branch passes before review.
* :doc:`specification-drafts` -- building, naming and versioning the
  specification drafts.
* :doc:`security-bugs` -- private reporting and disclosure.
* :doc:`code-of-conduct` -- conduct in issues, pull requests, reviews and
  security reports.
